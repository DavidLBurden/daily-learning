Day 3: September 6th, 2026  I learned about string concatenation and string interpolation.
Both are ways to combine text and variables together to create a string.
String ConcatenationString concatenation means joining two or more strings together.
In Python, you can use the + operator to combine strings.

For Example: 

first_name = "John"
last_name = "Doe"
full_name = first_name + " " + last_name
print(full_name)
The Output would be: John Doe


String interpolation is a way to insert variables directly into a string. In Python, one of the easiest ways to do this is with an f-string.

An f-string starts with an f before the quotation marks, and variables can be placed inside {}.

For example:

full_name = f"{first_name} {last_name}"

print(full_name)
The Output would be: John Doe

I learned that f-strings can make my code easier to read because I can put variables directly inside the string instead of using multiple + operators.

What I Learned 
The main difference is that string concatenation uses the + operator to join strings 
together, while string interpolation uses f-strings to insert variables directly into a string. Both are useful 
when working with text in Python, but I find f-strings easier
to read when I need to include multiple variables in a sentence.
